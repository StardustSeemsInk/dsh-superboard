# 教学法观察：一次真实讲课中有效的做法与失败的做法

**来源**：2026-10-14 至 10-15，用 SuperBoard 教 TU/e 2IV60 计算机图形学（16 单元，目标是期末笔试）。
**读者**：改教师 preset（`preset_teacher`）与教学类 Skill 的人。
**体裁**：一手教学记录 + 可执行建议。不是模型契约。

**为什么值得写**：这一轮里讲法**先失败、后成功**，两次都有用户的原话作为判据。失败与成功之间的差别是可以写成规则的，而且差别不在「讲得详不详细」，在**信息出现的顺序**。

---

## 1. 失败的做法：一句话塞完

第一版讲义是这么写「点积」的：

```markdown
**点积** —— V·W = |V||W|cos θ = VₓWₓ + V_yW_y + V_zW_z；可交换；
用于求夹角、求投影、判断垂直 —— 课件 p.22–26。
```

信息在事实层面上**全对**，而且省地方。用户的反应是：

> 「你讲课像在读说明书，我完全听不懂啊」(m00604)

**为什么听不懂**：这一句话里有 5 个未交代的符号（V、W、θ、·、|·|）、2 个公式、4 个用途、1 个引用。读者不知道 V 和 W 是什么东西、点积**是什么**、为什么要算它，就已经被告知它有四个用途。**这是手册的写法，不是讲课的写法。**

同一轮里还有一个更尖锐的例子。用户问「球坐标是什么东西」，我回答的是「哪个约定对」（课件标签与公式矛盾，应该以教材为准）。用户的原话：

> 「所以球坐标是什么东西？？法向量这给运算我完全看不懂你在干什么，能不能好好讲？」(m00574)

**教训**：用户问「X 是什么」时，回答「X 应该用哪个约定」是**答非所问**。**先给是什么，再给哪个对。**

## 2. 成功的做法：四步，术语只在第三步出现

改版后的固定结构：

| 步骤 | 做什么 | 禁忌 |
|---|---|---|
| **1 场景** | 一个带**具体数字**的真实问题 | 不要用「设向量 V」开头 |
| **2 手算 / 直觉** | 真的算一遍，或讲清「为什么需要它」 | 不要跳步；不要先给公式 |
| **3 命名** | **现在**才引入术语与公式 | 术语不得早于这一步 |
| **4 用途** | 一句话说它后面在哪用 | 不要列 4 条用途 |

「点积」按这个格式重写后是这样的（实际用在讲义里）：

```markdown
**场景**：光照程序里，表面法向箭头与太阳光方向夹角 30°，这个表面收多少光？

**直觉**：夹角越小，光越正着照，越亮；夹角 90° 完全照不到。
我们需要一个数字，能同时反映两个方向**以及它们的夹角**。

**命名**：这个数字叫**点积**，写法 V·W，两种算法：
    V·W = |V| |W| cos θ            几何：长度 × 长度 × 夹角余弦
    V·W = VₓWₓ + V_yW_y + V_zW_z    代数：逐项相乘再相加

**手算**：V=(1,0,0)，W=(0,1,0)。
代数：(1)(0) + (0)(1) + (0)(0) = 0。
几何：夹角 90°，cos 90° = 0。两种算法一致 ✔

**用途**：每个光照公式、每次求夹角、每次判垂直都用它。
```

**关键差别**：术语「点积」出现在第三行而不是第一行。读者在被告知这个名字之前，已经知道**需要一个数**、这个数该干嘛。名字只是给已经理解的量贴个标签。

用户对这一版的反馈：

> 「你的单元4的markdown文档中关于这道题的讲解很好，我现在觉得理解很清晰」(m00735)

### 2.1 建议（preset / skill 层）

1. **把四步式写进教师 preset 的输出契约**，作为讲解型回答的默认骨架。不是建议，是格式要求。
2. **加一条硬规则：任何符号第一次出现必须先解释。** 不是「解释一下」，是「先说明它是什么、怎么量、单位是什么」，然后才允许写进公式。这条能拦掉「读说明书」的大部分实例。
3. **禁止「公式 + 用途清单 + 出处」的单句结构。** 这类句子是手册体裁的产物，看到就要求拆成四步。
4. **用途最多写一条。** 四步式的第 4 步是「后面在哪用」，不是「本概念的完整应用谱系」。用途列长了会退化成手册。

## 3. 检查题：必须能手算

第一版检查题是概念题：

> 球坐标 (r, θ, φ) 里，θ 和 φ 各是什么角？

用户答不出来，因为题问的是**定义**，而定义正是他没接住的东西。

改版后：

> 一个点的球坐标是 **(r, θ, φ) = (2, 0°, 60°)**。它的 **(x, y, z)** 是多少？

用户答对：**(√3, 0, 1)**。

**建议**：
- **检查题必须有一个数值答案**，且答案能靠手算得到。概念题的失败信息量太低——答错只能说明「没记住」，数值题答错能暴露**错在哪一步**。
- **每页一题，答完停住。** 不要一页塞三题，也不要自问自答。
- **答错 = 上一块太大。** 这是用户明确认可的一条（「重新梳理一下教纲并改一改教学方式」）。答错时的正确动作是**把上一个概念拆小重讲**，不是把同一段话再说一遍。
- **题面本身不能暗示答案。** 见下。

### 3.1 题面措辞会污染答案（实测反例）

单元 5 我出了一题：绕一根**穿过原点、方向为 x 轴**的轴转 α，问总矩阵是什么。但题面我写成了：

> 按 5.3.1 那个三明治公式 `T(Q)·Rz(α)·T(−Q)`，这里 Q 取什么？M 最后等于什么？

学生的回答是「Q 取 (0,0,0)，M = Rz(α)」——**完全照着我的题面答**，然后立刻自己起了疑心：

> 「等等，绕 x 轴为什么是 Rz？用 Rx 不好吗？」

**他答对了，是我的题有问题。** 我在题面里直接写了 `Rz`，等于把「答案用哪个矩阵」这个考点替换成了「填一下 Q 是什么」。题面把一个本应被考察的选择**替学生做掉了**，而且做错了。

**教训**：检查题的题面**只能给场景和已知量，不能给解法骨架**。一旦题面里出现公式形式、字母、步骤顺序，学生就会照着填，考的就变成了「抄得像不像」。上面这题的正确题面是：

> 绕一根穿过原点、方向为 x 轴的轴转 α，总矩阵是什么？

**可写进 preset 的检查项**：出完题后回读一遍题面，问「答案里的关键选择，题面有没有提前给掉？」给了就重写。

**附带收获**：学生「先照题面答、再自己起疑」这个动作是**好信号**，应当明确表扬，而不是只判对错。这说明他在校验而不是记忆。

## 4. 材料有矛盾时：以第三来源裁决，并登记勘误

发现的事实：课件 `math1.pdf` p.11 的文字标签说球坐标的 φ 是 *elevation or latitude*（仰角），但**同一页的图和公式**（z = r cos φ）表明 φ 从 **+z 轴**量。教材附录 A §A.1.6 支持后者（「常数 φ 的曲面是锥顶在原点的圆锥」）。

**处理**：在讲义里明写「课件那页有个错，以教材为准」，并把勘误登记在总览页。

**建议**：教师 preset 应允许并鼓励**指出材料本身的错误**，而不是把矛盾含糊过去。学生照错的标签算，后面球面参数化、球面纹理映射会连着错。同时把勘误放在一个**集中的位置**（我们放在 main 页的一个块里），复习时可以只看那一条。

## 5. 源图不清楚时：自己画

课件原页在球坐标这件事上是「图对、标签错」，直接放原页会传播错误。做法是用 PIL 画了一张对照图：**同一条半径，蓝色 φ 从 +z 量、橙色 elevation 从赤道量**，一图说清「两个角都是角，本课用蓝色的那个」。

法向量那张同理：左「变形前」带直角标记，右「x 拉长 2 倍」后同时画出**正确的绿色 `(M⁻¹)ᵀn`** 与**打叉的红色 `Mn`**，两个方向一眼可分。

**建议**：不要只依赖课程 PDF 做视觉材料。**当原图本身是混淆源时，自绘一张对照图比原文更有效**，因为自绘图可以只画对比所需的两个量。

## 6. 看板侧的实践（与 board skill 有关）

这轮用 SuperBoard 承载讲课现场，以下几条实测有效：

1. **`masonry cols=2` 是讲课页的合适默认。** 概念块高度差异大，瀑布流不留空洞。（与 `docs/design/board-design-notes.md` §4.1 的描述一致，这里给出教学场景的实测取值。）
2. **把课件原页作为 `pdf-page` 块挂在讲解块旁边。** 学生可以就地对照原页，不用另开 PDF。`board_read` 会返回每行的归一化矩形，这给「指向原页的某一行」留了锚点。
3. **一块 = 一个概念，检查题单独一块，放页尾。** 不要在一页里讲完一整个单元。
4. **每个单元一页，页之间用 `next` 边串起来。** 讲到哪里、下一课是什么，看地图就能导航。
5. **讲课内容同时落成独立 Markdown 文档**（`单元/单元-0N-*.md`），看板当现场、文档当可复习的成品。用户后来明确要了这一步，且**对文档的评价高于对当场讲解的评价**（「文档中关于这道题的讲解很好」）。

**建议**：教学类 skill 应把「看板 = 讲课现场、Markdown = 可复习成品」这个双产物模式写成默认，而不是让学生事后自己去整理。

## 7. 一条值得单独记的：允许并主动纠正自己

2017 年卷一道填空题「齐次坐标下 (x₀,y₀,w₀)ᵀ + (x₁,y₁,0)ᵀ 的 x 坐标是多少」，我先前给出的答案是 `x₀/w₀ + x₁`，**是错的**；正确是 **(x₀ + x₁)/w₀**（先逐项相加，第二向量 w=0 故和仍为 w₀，再除以 w₀）。

那页试卷官方标注 **"Answers not available."** —— 所有填空答案都是推导所得，不是抄录。发现后改在讲义里并加了注。

**建议**：教师 preset 应当**明确允许说「我上一条讲错了」**，并把更正写进材料而不是悄悄改掉。推导型内容（试卷没给答案）尤其要有这条自觉。

## 8. 汇总：可写进 preset / skill 的规则

按重要性排序：

1. **讲解型回答用四步式：场景（带数字）→ 手算/直觉 → 命名 → 用途。** 术语只在第三步出现。
2. **任何符号第一次出现，先用日常语言说清它是什么、怎么量。** 违反这条就重写。
3. **禁止「公式 + 多用途 + 出处」的单句。**
4. **检查题必须有数值答案、能手算、每页一题、答完停住。**
5. **题面不能给解法骨架。** 出完题回读一遍：「答案里的关键选择，题面有没有提前给掉？」给了就重写。
6. **答错 = 上一块太大 → 拆小重讲，不要重复原话。**
7. **用户问「是什么」时，不要回答「哪个约定对」。**
8. **材料自相矛盾时，用第三来源裁决，公开指出错误，集中登记勘误。**
9. **原图是混淆源时自绘对照图。**
10. **允许并主动纠正自己的错误，更正写进材料。** 自己的题出错了也要当场承认并改，这比假装题没问题更能建立信任。
11. **双产物：看板当现场，Markdown 当可复习成品。**
