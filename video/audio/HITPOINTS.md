# 配乐时刻表（实际用的）

配乐是**代码合成的**（`audio/score.mjs`，Node 直接写 PCM → WAV），不是素材库的曲子。
理由是这首曲子要精确落在 ~31 个剪辑点上，而原创合成**零版权风险**、且改一个数字就能重排。

**总长 95.00 s，48 kHz 立体声 s16，峰值 0.6703，削波样本 0 个。**
**重渲染逐位一致**——噪声明源是固定种子的 xorshift32，没有跨次运行的随机状态。

所有时刻都从 `timeline.json` 读，所以**画面与音乐不可能对不上**：
改 `timeline.json` 的 `beatGrid`，重跑 `node audio/score.mjs` 即可。

---

## 网格：为什么是 BPM 120

| 常量 | 值 | 含义 |
|---|---|---|
| `BPM` | **120** | 一拍 0.5 s |
| `BEAT` | 0.5 s | |
| `BAR` | 2.0 s | 4/4 |
| `GRID` | 0.25 s | = `BEAT / 2`，所有重音都吸到这个格上 |

`timeline.json` 里**每一个镜头切换点都是整秒**。BPM 100（一拍 0.6 s）除不尽整秒，
八个切换点全落在拍与拍之间——那是"4 连鼓点有点不协"的**根因**，不是音色问题。
BPM 120 的一拍是 0.5 s，而 0.5 整除任何整秒，所以**八个切换点全部落在拍上**。

实测（30–120 Hz 频带能量，t = 70.0 s）：旧谱 **-25.8 dB**（最近的 kick 在 69.8 / 70.4，正好错过）
→ 新谱 **-16.9 dB**。

## 结构

| 段落 | 时间 | 做法 |
|---|---|---|
| 铺底 | 0 s 起 | 慢速 pad 和弦（每个音 3 条失谐正弦），克制、克制、再克制 |
| 一次脉冲 | 4 s | intro 里唯一一个 kick |
| 进入 | 8 s | 鼓组进入，stage 0：只有 kick |
| 加层 | 20 s | stage 1：kick + 小节内八分 hat |
| 加层 | 47 s | stage 2：加反拍 kick + 隔小节的 snare |
| 收束 | 89 s | 收束和弦（Am add9）+ 长尾音，余韵拖到最后一帧之后 |

## 节奏型是 half-time，不是每拍一鼓

```
kick    X . . . X . . .   ← 每小节第一拍；47 s 起在第三拍再加一个
hat     . . x . . . x .   ← 每拍后半格（八分），音量 0.12 / 0.19 交替
snare   . . . . . . S .   ← 47 s 起，隔一小节一次
```

每拍一个 kick 会推着一部本来要"平静"的片子走，所以改成 half-time，
并且整套鼓**分三段进入**（8 / 20 / 47 s），让片子一直有地方可去。

## 镜头切换点（`beatGrid.cuts`）

`8, 20, 34, 47, 60, 69, 81, 89`

每一个都拿到**两样东西**：

1. 一个 **riser**（提前 1.8 s 起，滤波截止随进度 `0.25 → 1.0` 打开，幅度按 `progress ** 1.6` 长起来）；
2. 一个 **`mallet` 重音**（gain 0.17，左右交替声像 ±0.3）。

重音的音高**从它下面那个和弦里取**：`CUT_DEGREE = [0, 1, 2, 3, 2, 1, 3, 2]`，
所以八个切换点串成一条在和声里上行的线，而不是同一个音敲八遍。

## 细化重音（`beatGrid.accents`，31 个）

`4, 8, 20, 22.2, 24.4, 26.6, 28.8, 34, 36.2, 38.4, 40.6, 42.8, 45, 47, 50.5, 55, 60, 61.5,
63, 64.5, 66, 67.5, 69, 72, 76, 79, 81, 83.7, 86.3, 89, 95`

与 `cuts` 重合的跳过（那些已经拿到 riser + 重音）。其余在用之前要过三道闸：

- **吸到 `GRID`**（`Math.round(accent / GRID) * GRID`）——画面事件是小数秒，格是 0.25 s；
- **同一格只用一次**（`usedSlots` 用 `cuts` 预置）——否则挤在一起的两个画面事件会变成一串连击；
- gain 只有 **0.07**、decay 0.22，音高取 `chordNotesAt(at)[(index * 3 + 1) % 4] + 12`。

让它读起来是"细节"而不是"事件"。其中几个是专门对着画面的：

| 时刻 | 对着什么 |
|---|---|
| 4 s | 标题卡上的软脉冲 |
| 22.2 / 24.4 / 26.6 / 28.8 | S2 每 ~2.2 s 切一页页签 |
| 36.2 … 45 | S4 六拍模板巡礼 |
| 50.5 | S5 深浅对比面板 |
| 55 | S5 "画不出来时，原因写回给它" |
| 61.5 … 67.5（每 1.5 s） | S6 每个行矩形落点 |
| 72 / 76 / 79 | S7 框选 / 文字选择 / 附件落袋 |
| 83.7 / 86.3 | S8 工程师 / 研究员预设 |
| 89 / 95 | 收束和弦 / 尾音 |

收尾（89 s 之后）是六个 pad 声部 + 一个 kick + 两个 `mallet`
（89.25 s 的 MIDI 76 与 90.10 s 的 MIDI 71，都是 Am add9 的和弦音，所以尾巴是"落到"而不是"淡掉"）。

## 音色是怎么来的

没有一个采样。全部是合成：

- **pad**：每个音 3 条失谐 ±4 音分的正弦，慢起慢落；
- **kick**：频率从 130 Hz 在 35 ms 内掉到 44 Hz，指数衰减——不用采样做出来的底鼓；
- **hat / snare**：固定种子的 xorshift32 噪声过一阶低通；
- **riser**：噪声的滤波截止随进度打开，低通中心 1200 Hz；
- **mallet**：基频 + **0.2 × 第 4 分音**，过 `lowPass(3600)`，decay 0.34。

### 两处音色是**按测量改的**，不是按口味

**① 「叮」原来是 `bell()`。** 它的分音是基频 + **2.76×** + **5.4×**——那是不谐的三角铁 / 钟琴频谱，
所以在密集混音里会像一根针。换成 `mallet()`：

- 用**第 4 分音**（马林巴的特征分音，是**谐波**关系，读起来是"木头"而不是"金属"）；
- 加 `lowPass(3600)`；
- 整体降八度。
- 同时治了一个更深的问题：31 个细化重音**原本全是同一个 MIDI 88（1318 Hz）**，
  所以连续几个重音就是一串嗒嗒嗒，没有旋律线。现在每个重音的音高都由它下面的和弦决定。

**② hat 变软了。** `lowPass(9000)` → **5200**，decay `0.018` → `0.035`，长度 `0.06` → `0.09`，音量下调。
理由：**9 kHz 的一阶低通套在 60 ms 噪声爆发 + 18 ms 衰减上，得到的是一个"嗒"，而"嗒"没有身体。**

**A/B 由频谱图证实**（`.tmp-ab/cmp-20-34.png`，上=旧 下=新，20–34 s）：旧谱有**五条宽而亮的高频带**（那些铃音），
新谱只剩干净等距的脉冲，几乎没有高频冲刷。

**总线**：`tanh(sample * 1.05)` 软限幅再钳到 ±1。硬削波会在这么密的混音里加进刺耳谐波；
tanh 压得住峰值又保持平滑——所以很多声部相加之后听起来仍然是干净的。

## 怎么重跑

```powershell
cd E:\Dev\dsh-superboard\video
node audio\score.mjs                       # → audio/promo-score.wav
node audio\score.mjs --duration 95 --out x.wav
```

`tools/build.mjs` 在最后合成阶段会自己读 `audio/promo-score.wav`；文件不存在就只输出无声画面
并打印一行说明，不会静默产出一个没有声音的成片。
